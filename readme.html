01

Get Started快速開始

  1. 用瀏覽器開啟（建議 HTTPS / localhost；file:// 可能封鎖定位與離線）。
  2. 按頂部 「＋ 新增座標」。
  3. 允許定位 → 「記錄目前位置」，或手動輸入緯度／經度 → 「以此座標儲存」。
  4. 資料自動存本機。重要資料請定期「匯出」備份。
＋ 新增→ 定位／輸入→ 標籤·照片→ 記錄→ 存檔✓

03

Record新增座標

A · GPS 定位

按「＋ 新增」→ 看橫幅狀態 → 「帶入下方」或「記錄目前位置」。沒定位就按記錄，會先定位再自動存。

B · 手動輸入

填 LAT／LNG（例 25.033000, 121.565400）→「以此座標儲存」或 Enter。

橫幅狀態顏色說明
待命灰尚未定位
定位中…橙閃取得 GPS 中
定位完成 ✓綠座標、精度、海拔
定位失敗紅按「重新定位」
連續記錄 勾「連續記錄」：存完不關面板，適合連打。名稱／備註／地址／照片會清空，標籤保留。

PWA安裝為 App

  1. 用 HTTPS 開啟（非 file://）。
  2. 按 「安裝App」 或選單「加入主畫面」。
  3. 同目錄需 sw.js 才能離線（頁尾 SW 已啟用）。
  4. 沒有 sw.js 也能用，只是不能離線開。

亮／暗色

頂部切換，偏好會記住。

螢幕常亮

定位中嘗試保持常亮。

14

FAQ常見問題

定位失敗？
確認瀏覽器定位權限；用 HTTPS；file:// 常被擋；按「重新定位」。iOS 需在系統設定允許瀏覽器定位。
地址查不到？
需連外網（Nominatim）。可手動填，或稍後「補地址」。同座標有快取。
匯入 CSV 失敗？
表頭要有「緯度」「經度」；數值在 ±90／±180 內；UTF-8 編碼。
照片會上傳嗎？
不會，只存你的瀏覽器 IndexedDB。
地圖空白？
圖磚與 Leaflet 需連網。離線時列表仍可用。連網後重開「地圖」。
資料會不見？
清瀏覽器資料、換瀏覽器可能遺失。定期「匯出」備份到雲端硬碟。

Format匯出格式範例

頂部「匯出」的 .txt 本質是 JSON：

{
  "v": 5,
  "tags": [
    { "id": "general", "name": "一般座標", "color": "#8b918a" }
  ],
  "defaultTag": "general",
  "points": [
    {
      "name": "三號電塔",
      "tags": ["general"],
      "lat": 25.033,
      "lng": 121.5654,
      "note": "巡檢點",
      "addr": "台北市中正區…",
      "time": "2026-01-15T08:30:00.000Z",
      "photos": []
    }
  ]
}
外勤建議流程 ① 出發：開工具、允許定位、看空間
② 現場：新增 → 標籤 → 拍照 → 記錄
③ 收工：補地址 → 改備註 → 匯出備份
