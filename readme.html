Quick Reference Guide

FIELD MANUAL座標記錄器 · 快速瀏覽

一款離線可用的本機座標筆記工具。資料只存在你的瀏覽器（IndexedDB）， 不會上傳伺服器。適合現場勘查、工程點位、外勤巡檢等需要快速記下位置與備註的場景。

01

Get Started快速開始

  1. 用瀏覽器開啟工具（建議 HTTPS 或 localhost；定位與離線功能在 file:// 下可能被封鎖）。
  2. 按頂部 「＋ 新增座標」。
  3. 允許定位權限 → 按 「記錄目前位置」，或手動輸入緯度／經度後按 「以此座標儲存」。
  4. 資料自動存進本機，關頁面再開仍在。重要資料請定期「匯出」備份。
＋ 新增→ 定位 / 輸入→ 標籤 · 照片 · 備註→ 記錄→ 自動存檔 ✓

03

Record新增座標

方式 A · GPS 定位

按「＋ 新增座標」→ 橫幅顯示定位進度 → 按「帶入下方」或「記錄目前位置」。尚未定位就按記錄，會先定位、鎖定後自動存檔。

方式 B · 手動輸入

填 LAT／LNG（十進位，例 25.033000, 121.565400）→ 按「以此座標儲存」或 Enter。

橫幅狀態外觀說明
待命灰色尚未定位，按「重新定位」開始
定位中…橙色閃爍正在取得 GPS
定位完成 ✓綠色顯示座標、精度、海拔
定位失敗紅色可按「重新定位」再試
連續記錄 勾選「連續記錄（儲存後不關閉）」：存完面板不關，適合連續打點。 名稱、備註、地址、照片在儲存後會清空；標籤選擇會保留。

05

Photos現場照片

拍照

開啟相機（手機預設後鏡頭）。

相簿

從圖庫多選圖片。

  • 照片會壓縮後存進 IndexedDB（最長邊約 900px、JPEG 品質約 70%），省空間。
  • 點縮圖 → 燈箱：雙指縮放、雙擊放大、拖曳平移、←→ 切換。
  • 燈箱下方：下載 / 刪除這張 / 開啟原圖。
  • 卡片上「＋ 照片」可替已有紀錄補拍、補傳。
隱私照片全部只留在你的瀏覽器裡，不會上傳任何伺服器。

09

Export / Import匯出與匯入

匯出

頂部「匯出」＝目前篩選後顯示的紀錄（.txt JSON）
匯出這筆＝單筆
批次匯出／CSV＝勾選的多筆

匯出時會詢問是否含照片；含照片檔案較大。

匯入

支援：
• .txt / .json：本工具匯出格式，或純 points 陣列
• .csv：表頭需含「緯度」「經度」（可選：名稱、標籤、地址、備註、建立時間）

標籤若不存在會自動建立。

備份提醒匯入前建議先匯出備份。CSV 欄位：名稱、緯度、經度、標籤、地址、備註、建立時間、照片數。

按頂部 「地圖」 開關地圖面板。

  • 圓點＝紀錄位置，數字＝列表序號。

PWA安裝為 App

  1. 用 HTTPS 開啟（非 file://）。
  2. 按頂部 「安裝App」，或用瀏覽器選單「加入主畫面」。
  3. 需同目錄有 sw.js 才能離線快取（頁尾顯示 SW 已啟用）。
  4. 沒有 sw.js 也能用，只是不能離線開啟。

亮色 / 暗色

按頂部切換；偏好記在 localStorage，下次維持。

常亮

定位中會嘗試保持螢幕常亮（支援的瀏覽器）。

Storage儲存與空間

項目說明
儲存位置IndexedDB（庫名 coordlog）；失敗時退回 localStorage（約 5MB）
空間條頁尾顯示目前用量／配額；超過 80% 變橙色
序列化失敗多半是照片過多 → 匯出後刪除部分照片
刪除全部頂部「刪除」＝刪除全部紀錄（含照片，不可復原，會再次確認）
換機搬移資料跟著「瀏覽器＋網站來源」走。用匯出 → 匯入搬移；瀏覽器帳號同步不保證涵蓋 IndexedDB，仍建議手動匯出。

FAQ常見問題

定位失敗？
確認瀏覽器定位權限；用 HTTPS 開；file:// 常被封鎖；按「重新定位」再試。iOS 需在系統設定開啟定位給瀏覽器。
地址查不到／逾時？
需能連外網（OpenStreetMap Nominatim）。可手動填地址，或稍後按「補地址」。同座標結果有快取，重查較快。
匯入 CSV 失敗？
表頭必須有「緯度」「經度」；數值需在有效範圍（緯度 ±90、經度 ±180）；檔案需 UTF-8（含 BOM 亦可）。
照片會不會上傳？
不會。全部只留在你的瀏覽器 IndexedDB 裡，工具沒有任何伺服器端儲存。
地圖是空的／打不開？
地圖圖磚與 Leaflet 需連網載入。離線時列表仍可用，地圖可能空白。確認網路後重開「地圖」。
資料會不見嗎？
清除瀏覽器資料、網站資料、或換瀏覽器都可能導致遺失。請定期按「匯出」備份 .txt 到雲端硬碟或電腦。

Data Format匯出格式範例

頂部「匯出」的 .txt 本質是 JSON：

{
  "v": 5,
  "tags": [
    { "id": "general", "name": "一般座標", "color": "#8b918a" }
  ],
  "defaultTag": "general",
  "points": [
    {
      "name": "三號電塔",
      "tags": ["general"],
      "lat": 25.033,
      "lng": 121.5654,
      "note": "巡檢點",
      "addr": "台北市中正區…",
      "time": "2026-01-15T08:30:00.000Z",
      "photos": []
    }
  ]
}
建議工作流（外勤） ① 出發前：開啟工具、允許定位、確認空間足夠
② 現場：新增座標 → 選標籤 → 拍照 → 記錄（可開連續記錄）
③ 收工：搜尋補地址 → 編輯備註 → 匯出備份一份
